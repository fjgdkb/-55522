ID3算法解读

ID3算法概述

ID3（Iterative Dichotomiser 3）算法是由Ross Quinlan在1986年提出的决策树学习算法，它使用信息增益作为属性选择的标准。

核心概念

信息熵

信息熵是度量样本集合纯度的指标，定义为：

Entropy(D) = -Σ(p_i × log₂(p_i))

其中p_i表示第i类样本在数据集D中所占的比例。

信息增益

信息增益表示使用属性a进行划分所获得的信息纯度提升：

Gain(D, a) = Entropy(D) - Σ(|D_v|/|D| × Entropy(D_v))

ID3算法步骤

  1. 计算数据集的信息熵
  2. 对每个属性计算信息增益
  3. 选择信息增益最大的属性作为分裂属性
  4. 根据该属性的不同取值创建分支
  5. 对每个分支递归执行上述过程

示例：天气数据集

数据集：

  • 属性：天气（晴、阴、雨）、温度（热、温、凉）、湿度（高、正常）、风力（强、弱）
  • 类别：是否打网球（是、否）

计算过程：

1. 计算整体信息熵

2. 计算每个属性的信息增益

3. 选择信息增益最大的属性作为根节点

ID3算法的优缺点

优点：

  • 理论清晰，方法简单
  • 学习能力较强
  • 适合处理大规模数据集

缺点：

  • 倾向于选择取值较多的属性
  • 只能处理离散型属性
  • 对噪声数据比较敏感
  • 没有剪枝策略，容易过拟合

ID3算法伪代码

function ID3(D, A): // D:数据集, A:属性集
  创建节点node
  if D中所有样本属于同一类别C then
    将node标记为C类叶节点
    return node
  end if
  if A = ∅ OR D中样本在A上取值相同 then
    将node标记为叶节点，类别为D中样本数最多的类
    return node
  end if
  从A中选择最优划分属性a*
  for a*的每一个值a*_v do
    为node生成一个分支
    令D_v表示D中在a*上取值为a*_v的样本子集
    if D_v = ∅ then
      将分支节点标记为叶节点，类别为D中样本最多的类
    else
      以ID3(D_v, A\{a*})为分支节点
    end if
  end for
  return node
